# Student Management System

A simple **Student Management System** built using **Python and Object-Oriented Programming (OOP)**. The program allows users to add, view, search, update, and delete student records through a menu-driven console interface.

## 🛠️ Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Lists
* Classes and Objects
* Loops and Conditional Statements
* User Input

## ✨ Features

* Add multiple student records
* Prevent duplicate Student IDs
* View all student details
* Search students by Student ID
* Update student marks
* Delete student records
* Menu-driven console interface

## 📚 OOP Concepts Used

### 1. Classes and Objects

The project uses two classes:

* `Student` — stores individual student information.
* `StudentManagementSystem` — manages the collection of students and performs operations.

### 2. Constructor

The `__init__()` method initializes student details such as:

* Student ID
* Name
* Age
* Marks

### 3. Encapsulation

Student data is stored inside `Student` objects and accessed through their attributes and methods.

### 4. Methods

Different methods are used to perform operations:

```text
add_students()
view_students()
search_student()
update_marks()
delete_student()
```

## 📋 How It Works

When the program starts, it displays a menu:

```text
===== STUDENT MANAGEMENT SYSTEM =====

1. Add Students
2. View Students
3. Search Student
4. Update Marks
5. Delete Student
6. Exit
```

The user selects an option and the corresponding operation is performed.

## 🔎 Example

A student can be added by entering:

```text
Student ID: 101
Student Name: Aarav
Age: 19
Marks: 85
```

The system stores the information as a `Student` object.
